# archive_v1

Files from the v1 analysis (old GitHub repository, merged into this project on 24 Oct 2026 in
commit ef1a8ac) and stray copies, moved here on 24 Oct 2026 so that results/ and scripts/ hold
only the v2 pipeline. Nothing here is used by the v2 scripts, and no number in these files
should be quoted in the v2 manuscript: the v2 results are in results/ (see results/numbers.csv).

- results/   v1 tables and figures (e.g. Table1-5, Figure1-4, Supplementary_Table_*, Yao2021_*)
- scripts/   v1 analysis scripts and their backups
- signatures/, data/processed/   v1 signature files and processed data
- HANDOVER.md, PENDING.md, STATUS.md, BenchMark3.Rproj, docs/gene_mapping.csv   v1 notes
- stray/     duplicate or misplaced copies found in the project root and scripts/
Kept in place: docs/ (literature coding, reporting completeness, cohort overlap, v1 deviations log).
